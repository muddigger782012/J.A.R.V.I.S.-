Reviewed voice screen control through Android Accessibility:

- Read supported visible content and list controls locally.
- Select a control by label or current number, review the target and explicitly confirm one tap. Duplicate labels require a numbered choice.
- Scroll exposed areas and request Android navigation, notifications and Quick Settings.
- Share one private review state between background voice and chat. Expire stale reviews, reject changed screens and cancel queued work on timeout.
- Keep locked, recognized password, permission, installer, Android Settings and SystemUI screens protected. Android Accessibility enabling remains a manual system flow.
- Preserve the HUD, themes, settings, voice, offline features and personal provider/model controls.

Release preparation now generates and verifies production-signed manifests, checksums and versioned downloads automatically. Updater publication waits for unit, gateway, theme and actual Accessibility emulator acceptance. Historical download publication preserves any newer updater APK.

These controls do not yet provide arbitrary typing, coordinate gestures or autonomous cross-app task execution. Android accepting a request is reported separately from its final outcome.
