# Jarvis Keyboard updates

Latest: 1.14 (versionCode 15). Upgraded voice dictation: live preview and activity meter, continuation after final phrases up to 90 seconds, Done/Cancel, improved spacing and stale callback guards. Automatic engine no longer forces offline preference; optional on-device-only mode and supported punctuation/personal-dictionary hints. Uses the phone's installed speech service; no new model bundled. Accuracy and new device integration remain unverified on phone.

Open Jarvis Keyboard > Updates to check and download. Android may require installation confirmation or install-source permission. Feed/APK validation is performed before installation.

Signed APKs and latest.json only. Application source and signing keys remain private. This distribution branch is separate from the main Jarvis application.
